# Fluez Eventos — prévia de landing page

Prévia comercial responsiva para a Fluez Eventos, criada a partir de informações públicas verificáveis. O objetivo da página é explicar a gestão completa de eventos e transformar visitas em pedidos de orçamento pelo WhatsApp.

## Direção visual vigente

- violeta e laranja derivados da comunicação pública da marca;
- grafite para reforçar a presença corporativa e o contraste;
- tipografia geométrica editorial, composição fotográfica ampla e linha de fluxo como elemento distintivo;
- fotografias públicas reais organizadas como bastidores, planejamento, montagem e entrega;
- imagens complementares geradas por IA identificadas como ilustrativas.

A versão de 22/09/2026 abandonou a estrutura de cartões repetidos e passou a usar
uma narrativa contínua: posicionamento, sistema de serviços, caso Chromoplast,
método, presença humana e briefing. A interação é uma camada adicional; todo o
conteúdo permanece utilizável com movimento reduzido.

## Executar localmente

```powershell
npm run dev
```

Acesse `http://localhost:3010`.

## Verificações

```powershell
npm run check
npm run build
```

O build estático é gerado em `dist/`.

## Situação de uso

Esta é uma demonstração. Nenhum material deve ser publicado comercialmente antes da confirmação dos dados, autorização das imagens e aprovação da Fluez.
